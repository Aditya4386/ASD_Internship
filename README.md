## 📁 Project Description
This project performs **Exploratory Data Analysis (EDA)** on Google Play Store data to uncover patterns and trends.

Key objectives:
- Analyze app ratings distribution
- Identify top app categories
- Study installs (Free vs Paid apps)
- Understand correlation between reviews, installs, and ratings
- Perform sentiment analysis on user reviews

---

## 🛠️ Technologies Used
- Python 🐍
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📊 Key Insights

- ⭐ Most apps have ratings between **4.0 and 4.5**
- 📱 **Family and Game categories** are the most popular
- 💰 Majority of apps are **Free (~92%)**
- 📈 Strong correlation between **reviews and installs**
- 😊 Most user sentiments are **positive**
